# PDC Barbería — Sistema

App de gestión para PDC Barbería: turnos, servicios, membresías, caja, comisiones y PDC Score.

> ⚠️ **Importante (etapa de prueba):** Esta versión guarda los datos en el navegador de cada dispositivo (no se comparten entre teléfonos).

## Cómo actualizar (conectado a GitHub)

1. Reemplazá los archivos de este proyecto en tu repositorio de GitHub (o hacé commit de los cambios).
2. Vercel detecta el push y vuelve a desplegar automáticamente.
3. El link no cambia.

## Cómo correr en tu compu (opcional)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # genera dist/ lista para subir
```
